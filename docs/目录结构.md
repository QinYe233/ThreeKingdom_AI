## 目录说明

### frontend/

React + Vite 前端应用，负责用户界面和地图渲染。

- **components/**: UI 组件，按功能模块分类
  - `Map/`: 地图渲染组件（Canvas 2D）
  - `UI/`: 界面面板组件
- **hooks/**: 自定义 React Hooks，封装复用逻辑
- **stores/**: Zustand 状态管理，轻量级全局状态
- **types/**: TypeScript 类型定义
- **utils/**: 工具函数和 API 客户端

### backend/

Python FastAPI 后端应用，负责游戏逻辑和 API。

- **api/**: FastAPI 路由，RESTful API 端点
- **core/**: 游戏核心逻辑（战斗、经济、迷雾、史官）
- **ai/**: AI 决策模块（LLM 客户端 + 规则引擎）
- **models/**: Pydantic 数据模型
- **data/**: 运行时数据（存档、配置、地图）

### src-tauri/

Tauri 桌面应用打包配置。

- **src/main.rs**: Rust 主程序，负责启动后端进程、窗口管理
- **binaries/**: 打包的后端可执行文件
- **tauri.conf.json**: Tauri 配置（窗口、安全策略、打包选项）

### scripts/

开发脚本，自动化常见任务。

- `SanGuo.ps1`: 启动前后端服务
- `Stop-SanGuo.ps1`: 停止所有服务
- `install-deps.ps1`: 检查并安装依赖
